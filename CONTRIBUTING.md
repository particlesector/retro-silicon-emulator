# Contributing

Thanks for helping build Retro Silicon Emulator.

- Discuss major architectural changes in an issue before implementation.
- Keep platform-specific APIs out of the core library.
- Include tests for behavioral changes and deterministic reproduction cases for bug fixes.
- Use C++23, CMake and descriptive commit messages.
- Do not commit copyrighted ROMs, BIOS dumps or third-party emulator source without permission and compatible licensing.
- Contributions are submitted under the repository's Apache-2.0 license.
