# NMOS 6502 reference vectors

`vectors.txt` contains the first 64 cases per documented opcode from
[SingleStepTests/65x02](https://github.com/SingleStepTests/65x02), `6502/v1`, pinned
to commit `2f6980a2d95757486c7bee24355c360e40e2a224`. These 9,664 cases include
NMOS decimal arithmetic; they are separate from the Ricoh fixtures.
The source data is MIT-licensed; see [LICENSE](LICENSE).

Regenerate with `./tools/import_cpu_vectors.ps1 -Processor 6502` in PowerShell.
Builds/tests need no network access. The format and transcription rules match
the [Ricoh fixture format](../nes6502/README.md). Each record occupies one line.
No expected results are generated by this project's CPU implementation.

SHA-256 (LF file): `074c8ee46fcd50c61e4ae07d7ab646d1ad29ae01ee724f6890dbb3d04ba65608`.
